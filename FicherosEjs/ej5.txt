Ejercicio 5. Clasificación de incidencias de aula
Se quiere procesar un fichero incidencias.txt. Cada línea tiene el formato alumno;tipo, donde tipo puede
ser retraso, tarea, material o comportamiento.


Ejemplo de fichero incidencias.txt:
Pablo:retraso
Manuel:material
Diego:tarea
Beatriz:comportamiento



a) Define una clase Incidencia con los atributos alumno y tipo.
public class Incidencia {

    private String alumno;
    private String tipo;

    public Incidencia(String alumno, String tipo) {
        this.alumno = alumno;
        this.tipo = tipo;
    }

    public String getAlumno() {
        return alumno;
    }

    public String getTipo() {
        return tipo;
    }
}



b) Lee todas las líneas del fichero y almacena las incidencias en un ArrayList<Incidencia>.

BufferedReader br = new BufferedReader(new FileReader("incidencias.txt"));

String linea;



ArrayList<Incidencia> inci = new ArrayList<>();

while ((linea = br.readLine()) != null) {

    String[] partes = linea.split(";");

    String alumno = partes[0];
    String tipo = partes[1];

    Incidencia i = new Incidencia(alumno, tipo);

    inci.add(i);
}



c) Usa un HashMap<String, Integer> para contar cuántas incidencias tiene cada alumno.

HashMap<String, Integer> n_inci = new HashMap<>();

for (Incidencia i : inci) {

    String alumno = i.getAlumno();

    n_inci.put(alumno,n_inci.getOrDefault(alumno, 0) + 1);
}





d) Usa otro HashMap<String, Integer> para contar cuántas incidencias hay de cada tipo.

HashMap<String, Integer> tipos = new HashMap<>();

for (Incidencia i : inci) { //recorremos el ArrayList   

    String tipo = i.getTipo(); //cogemos el tipo de incidencia

    tipos.put(tipo,tipos.getOrDefault(tipo, 0) + 1); 
    //sumamos 1 en el hashmap y con get or default cogemos el valor de tipo lo que hacemos es   
    //le sumamos 1
    //si el tipo existe -> devuelve su valor
    //si no existe -> devuelve 0
}
